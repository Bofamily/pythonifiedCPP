A little more Pythonic ✨

Write C++ with a friendlier feel.

Pythonified C++ is a small C++ library that brings familiar Python-style helpers to your projects — making everyday code feel a bit more readable and approachable.

Get started → Explore the source code

Lightweight · Header-based · Easy to add to an existing C++ project

main.cpp
// Make C++ feel a little more familiar
#include "pythonifiedCPP.h"

int main()
{
    print("Hello, World!");

    // Wait for one second
    pytime::wait(1000);

    print("Goodbye, World!");
    return 0;
}
A familiar, simple way to add a little Python-inspired convenience to C++.

Pythonified C++ keeps things simple: a collection of convenient functions designed to make common tasks feel more straightforward.

What's included

Meet the helpers

The current README documents these functions. More can be added as the library grows.

print(input)

Console

Prints the supplied input to the console and returns 0.

print("Hello, World!");

pytime::wait(ms)

Timing

Waits for the specified number of milliseconds. For example, 1000 is one second.

pytime::wait(1000);
Up and running

Getting started is easy.

Pythonified C++ is designed to slot into a C++ project without a complicated setup process.

Get the header on GitHub ↗
1
Get the header

Download pythonifiedCPP.h from the repository.

2
Add it to your project

Place the header in your project's include directory.

3
Include and use it

Add #include "pythonifiedCPP.h" and start using the helpers.
